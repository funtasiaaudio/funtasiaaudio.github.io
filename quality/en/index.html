Quality Assurance

Test carefully. Improve continuously. Support creativity.

FUNtasia Audio strives to make free and paid plugins dependable tools for music production. We combine automated validation, checks on real Windows systems and in DAWs, and regression testing—and continue improving after release.

pluginval — Strictness Level 10

We run pluginval at Strictness Level 10, its highest available setting. It checks areas such as plugin loading, audio processing, parameters, and state handling under demanding conditions. The “10” represents test strictness, not a quality score out of 10.

Steinberg VST3 Validator — Extensive Tests

We use Steinberg’s official VST3 Validator for VST3 format and host interaction checks. Alongside standard validation, we run Extensive Tests, including checks of initialization, audio buses, parameters, processing, and state management.

Functional and regression testing

After changes or fixes, we check that existing features still work as intended. Coverage is tailored to each product, with attention to the following areas:

  • DSP behavior and audio output
  • DAW automation and parameter handling
  • Undo / Redo
  • Preset and project save/restore
  • GUI behavior and display
  • Supported sample rates and processing modes
  • Previously fixed bugs

Passing tests is not a guarantee of zero bugs

A passing result is meaningful evidence that no issue was detected under the tested conditions. But no test process can cover every combination of DAW, operating system, hardware, and workflow. Quality assurance continues after release through fixes and further testing.

Help us make FUNtasia better.

If you encounter a bug, an awkward workflow, or have an idea for improvement, please join our official FUNtasia Alchemist Guild Discord community. Your feedback helps us reproduce and fix problems and shape future updates. We want to build better music-making tools together.

For bug reports, please include the product and version, OS, DAW, reproduction steps, and observed behavior.
