FUNtasia Quick Launcher

創作のワークスペースへ、すぐアクセス。Ctrl + Alt + Spaceで呼び出せる、キーボード中心の軽量Windowsランチャーです。アプリ、ファイル、フォルダー、URLの検索・起動をひとつにまとめます。

Ctrl + Alt + Spaceドラッグ＆ドロップで追加ショートカットの並べ替え・ピン留め日本語 / EnglishFUNtasia Studioの7色テーマWindows起動時の自動起動（任意）

標準アイコンはOriginal Sage。Charcoal、Deep Brown、Lapis Lazuli、Lavender、Coral Red、Mikan Orangeの6色も、ショートカットの着せ替え用アイコンとして用意しています。

公開中 · v1.0.0 · Windows 11

FUNtasia Mixer

Windows 11の通知領域から使える、コンパクトなアプリ別ボリュームミキサー。アプリごとの音量調整やミュート、操作する出力デバイスの選択、よく使うアプリのピン留めに対応しています。

FUNtasia Studioに合わせた7色のテーマと、Kaisei Optiを使った落ち着いたデザイン。選択した出力デバイスの音量を操作でき、Windowsの既定の出力デバイスは切り替えません。

公開中 · v1.2.1 · Windows x64 · 無料

FUNtasia Player

再生のためのシンプルなスタンドアロン・オーディオプレーヤー。Windowsからファイルを開くかドラッグ＆ドロップし、再生・停止・リピート・シーク・音量を操作できます。

WAV / FLAC / MP3 / AIFFASIO / WASAPI再生・一時停止・停止リピート・シーク・音量ドラッグ＆ドロップファイルの関連付けタイトル・アーティスト情報アートワーク表示7色テーマ5言語マニュアル

v1.2.1ではASIO対応の音声出力設定と7色のテーマに対応。出力デバイスとテーマの選択を保存します。EQ・ノーマライズ・リミッター・サチュレーションなどの音声処理は追加しません。

Windows 11 · x64 · 公開ベータ v0.1.0k

FUNtasia Session Note

ひらめきを残して、音楽へ。制作セッションごとにアイデア・メモ・ToDoをまとめ、BPM・キー・進行状況も記録できる軽量デスクトップアプリです。

ローカル自動保存、日本語／English切替、Kaisei Opti内蔵、7色のダークテーマ、最前面固定、Ctrl + Alt + Nでの表示切替に対応。作曲の流れを邪魔せず、必要なときだけ呼び出せます。
